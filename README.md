- Descripción general del sistema

LlanquihueTour es un projecto hecho en java para una agencia de turismo
ubicada en la region de los Lagos.
El programa te deja crear y mostrar informacion de las personas, los empleados y sus direcciones.
Para este  programa se utilizaron diferentes ,clases que permiten organizar la información.
La clase Empleado utiliza datos de Persona,mientras que Direccion permite guardar la dirección de cada persona.

Con este projecto pude practicar lo que aprendido como la programacion orientada en objectos en java, y mejorar otras cosas como 
las clases.
